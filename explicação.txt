GUIA DE USO — ATIVIDADES DE COMPILADORES
=========================================

Primeiro clone o repositório:
git clone https://github.com/JoaoR090/atividades-compiladores.git

Este arquivo contém as instruções para executar cada uma das atividades
presentes neste repositório.


ATIVIDADE 1 — ALGORITMO TPP
===========================

Localização:
atividades/1-Algoritmo_tpp/

Arquivo:
codigo_para_teste.tpp

Descrição:
Arquivo contendo um algoritmo escrito na linguagem TPP para testes.

Uso:
O arquivo codigo_para_teste.tpp é utilizado como entrada para os testes
relacionados à linguagem TPP.

Exemplo:

    codigo_para_teste.tpp


ATIVIDADE 2 — EXTRAÇÃO DE E-MAILS
=================================

Localização:
atividades/2-Extração_de_emails/

Arquivos:
emails.txt
pegue_email.c
pegue_email.cpp

Descrição:
Os programas foram desenvolvidos em C utilizando Expressões
Regulares para localizar e recuperar os e-mails presentes em um arquivo.

Formato de execução:

    código_compilado arquivo_a_ser_procurado

Exemplo em C:

    ./pegue_email emails.txt

Observação:
O primeiro argumento é o programa compilado e o segundo argumento é
o arquivo que será analisado.

O arquivo emails.txt é apenas um exemplo de entrada. É possível informar
outro arquivo contendo os dados que deverão ser pesquisados.


ATIVIDADE 3 — EXTRAÇÃO DE TAG HTML
==================================

Localização:
atividades/3-Extracao_tag_html/

Arquivos:
pegue_tag.cpp
teste_html.html

Descrição:
O programa utiliza Expressões Regulares para localizar e recuperar o
conteúdo de uma tag HTML escolhida pelo usuário.

Formato de execução:

    código_compilado arquivo_a_ser_procurado tag

Exemplo:

    ./pegue_tag teste_html.html p

Nesse exemplo, o programa irá procurar no arquivo "teste_html.html"
o conteúdo das tags <p>...</p>.

Outro exemplo:

    ./pegue_tag teste_html.html h1

Nesse caso, serão procurados os conteúdos das tags <h1>...</h1>.

Observação:
A tag deve ser informada sem os caracteres "<" e ">".

Exemplo correto:

    p
    h1
    div
    title

Exemplo incorreto:

    <p>
    <h1>


ATIVIDADE 4 — HIGHLIGHT SYNTAX
==============================

Localização:
atividades/4-Highlight_Syntax/

Descrição:e a 
Esta atividade consiste em uma extensão do Visual Studio Code que
adiciona syntax highlighting para a linguagem TPP.

O arquivo da extensão já compilada está localizado em:

    tpp-language-0.0.1.vsix


INSTALAÇÃO DA EXTENSÃO
----------------------

1. Abra o Visual Studio Code.

2. Abra a aba de extensões.

3. Clique no menu de opções das extensões (ícone de três pontos).

4. Selecione:

       "Install from VSIX..."

5. Selecione o arquivo:

       tpp-language-0.0.1.vsix

6. Após a instalação, abra um arquivo com extensão .tpp.

A extensão deverá reconhecer a linguagem TPP e aplicar o
syntax highlighting.


ESTRUTURA DA ATIVIDADE 4
------------------------

A pasta contém os arquivos utilizados para desenvolver a extensão:

    tpp-language/
        syntaxes/
        language-configuration.json
        package.json

Também está disponível o arquivo já compilado:

    tpp-language-0.0.1.vsix

Para utilizar a extensão, não é necessário recompilá-la. Basta instalar
o arquivo .vsix no Visual Studio Code.

OBSERVAÇÕES
===========

- Os nomes dos executáveis podem variar de acordo com o nome utilizado
  durante a compilação.
- Os arquivos de entrada devem ser informados corretamente no momento
  da execução.
- Na Atividade 3, a tag deve ser informada sem "<" e ">".
- A Atividade 4 já possui uma versão compilada da extensão no formato
  .vsix.
